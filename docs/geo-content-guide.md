# GEO 콘텐츠 작성 가이드 (블로그)

생성형 엔진(ChatGPT Search·Perplexity·Claude·Google AI Overviews)이 집현전 블로그 글을
**인용·노출**하도록 돕는 작성 컨벤션. 근거: GEO 연구(Aggarwal et al., KDD 2024) + 후속 산업 분석.

## 시스템이 자동 처리하는 것 (작성자는 신경 쓸 필요 없음)
- 서버 렌더링(SSR): 발행 글은 JS 없이도 본문·메타·JSON-LD가 크롤러에 노출됨
- `BlogPosting` JSON-LD, `<title>`/OG/Twitter 메타: 제목·excerpt로 자동 생성
- `sitemap.xml`·`feed.xml`·`llms.txt`: 발행 즉시 자동 포함
- 언어: 제목/본문의 한글 여부로 `inLanguage`·`og:locale` 자동 판별(ko/en)

## 작성 체크리스트 (영향력 큰 순)
1. **첫머리 2~4문장 요약(TL;DR)** — 글이 답하는 핵심 질문에 곧장 답한다. "이 글에서는…" 같은 군더더기 금지. (이 요약을 `excerpt`에도 넣으면 메타 설명으로 재사용됨)
2. **출처를 이름과 함께 인용 + 링크** — GEO에서 가장 큰 노출 상승 요인. "Aggarwal 외(2024)에 따르면…"처럼 본문에 출처를 명시한다.
3. **구체적 통계·수치 1개 이상** — 모호한 주장보다 숫자가 인용된다.
4. **리뷰 대상 논문을 직접 인용** — 딥리뷰 결과의 핵심 문장을 그대로 따온다.
5. **추출 가능한 구조** — H2/H3(가능하면 질문형 제목), 리스트/표 활용. 긴 글은 말미에 짧은 **FAQ** 추가.
6. **엔티티 명시** — 집현전/Jiphyeonjeon, 다루는 논문·저자를 이름으로 분명히 적는다.
7. **신선도 유지** — 글을 갱신하면 `updated_at`이 올라간다. 최신성은 인용 요인.
8. **키워드 스터핑 금지** — 측정상 오히려 역효과. 연구자 독자를 위해 자연스럽게 쓴다.

## 측정
- 발행 며칠 뒤 글이 답하는 질문을 ChatGPT Search/Perplexity/Claude에 직접 물어 인용 여부 확인
- 서버 로그(`middleware.py`)에 AI 크롤러·AI 리퍼럴이 INFO로 기록됨 → 방문 추적
