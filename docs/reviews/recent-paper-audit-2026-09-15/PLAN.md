# 최근 발행 논문 리뷰 검토·수정

## 범위와 기준

- 공개 API에서 확인한 2026-09-06~2026-09-15 발행 논문 리뷰 10편. 처음 로컬에 있던 6편과 본문이 같은지 확인하고, 로컬에 없는 최신 4편은 공개 원본을 별도 보존했다.
- 기존 작업 파일을 되돌리지 않는다. `baseline-posts.json`은 작업 시작 시점 로컬 상태이며 `articles/*/live-original.json`은 공개 게시본이다.
- 기존 구조·그림·URL을 보존하면서 기술 설명, 실험 해석, 수치·출처 정확성을 개선한다. 작업 기록은 보고서에 두고 공개 본문에 반복 삽입하지 않는다.
- 새 논문의 발행이 아니라 기존 발행본의 수정이다. 배포는 별도 실행되지 않으며, 로컬 게시 데이터와 검토 가능한 수정본을 산출한다.

## 에이전트 분담

| 담당 | 작성·분석 | 독립 후속 검토 |
| --- | --- | --- |
| agent_methods | AMD, Procedural Graphs, TTPO | 다른 담당의 7편 사실·정의 검증 |
| causality_retrieval | CFM, RAG vs. GraphRAG, CodeNib | 다른 담당의 7편 비판 검토 |
| publication_map | 저장소·기존 근거 경로 및 공개 목록 구조 조사 | 로컬 원문 대조 보조 |
| leader | RSI Roadmap, InCoder, CLAUSE, WikiProfile | 통합, 피드백 재판정, 게시 스키마·렌더링 검증 |

## 완료 기준

1. 원문 판본과 주요 수치·방법 설명을 대조하고 근거·방법·결과·비판 기록을 남긴다.
2. 수정본을 다른 담당자가 검토하며, 근거가 부족한 비판은 삭제하거나 직접 추론임을 밝힌다.
3. 수정본, JSON, 참조 그림, 수식 렌더링, 블로그/SEO 관련 테스트를 확인한다.
4. 대상 외 게시물과 기존 메타데이터 보존을 확인한다.
5. 로컬 반영 상태와 공개 사이트·PaperWiki 반영 여부를 구분해 보고한다.
