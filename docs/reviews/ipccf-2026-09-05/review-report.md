## 1. 총평

기존 글은 성능표 전사와 주요 실험 한계를 대체로 정확하게 다룬다. 18개 평가 칸의 순위, 평균 상대 개선, 절제 하락률, MAD의 예외, 목표 성능 도달 시간의 제한은 그대로 살릴 가치가 있다. 문제는 숫자 자체보다 **핵심 연산을 생략한 설명, 절제의 인과적 해석, 공개 구현의 중요한 차이를 충분히 드러내지 않은 점**에 있다.

수정문은 원문의 9개 절 구조를 유지하면서 다음을 우선 보강했다.

1. 테스트 지표로 최적 에폭을 고르는 공개 코드의 평가 절차.
2. 아이템 표현의 인덱스 오류와 조건부 간선 순서 문제.
3. cosine/내적, 점수 비율/softmax, 독립 의도 손실의 차이.
4. 의도별 이웃 정규화 → 의도 평균 → 메시지 전파의 정확한 순서.
5. 큰 모듈 제거 효과와 세부 장치의 독립 기여를 구분하는 결론.

이는 논문 전체를 무효화한다는 판정이 아니다. 공개 코드의 문제는 확인한 커밋에 한정하며, 그 코드가 논문 결과를 생성한 실행본인지는 확인하지 못했다.

## 6. 기존 글에서 바뀐 표현의 예

**기존 해석:** 독립 의도 제약으로 거의 직교하고 LightGCN이 선형이므로 평균 전파가 가능하다.

**수정:** 같은 메시지 M을 각 의도별 행렬에 전파한 뒤 평균하는 연산은 선형성으로 평균 행렬 전파와 같다. 이 등식에는 의도 벡터의 직교성이 필요하지 않다. 의도별 투영·재구성 전체의 동치와는 구분한다.

**기존 해석:** 최선 기준선과의 격차를 결정하는 핵심은 2-hop 동종 구조에서 의도를 전파하는 부분이다.

**수정:** 두 관련 모듈을 제거했을 때 큰 하락이 나타나 전체 모델 안에서의 중요성은 지지된다. 다만 구조 경로와 메시지 전달을 함께 바꾸는 절제이므로 세부 장치의 독립 효과는 분리되지 않는다.

**기존 재현성 설명:** seed·patience, 층 합/평균, 배치, FCNN, 독립 의도 손실 차이를 제시한다.

**수정:** 테스트 기반 모델 선택과 아이템 인덱스 오류를 우선 추가하고, 가중치 함수 차이를 명시한다. 층 합/평균은 고정 임베딩의 순위에는 영향을 주지 않지만 학습 스케일에는 영향을 줄 수 있다고 제한한다.

## 7. 최종 검증 기록

- 근거 추출과 방법 재구성, 공개 코드 감사를 독립적으로 수행한 뒤 통합했다.
- 초안 이후 실험 verifier와 방법론 critic의 두 번째 검토를 받았다.
- 검증한 주요 항목: 논문 메타데이터, 주 결과·절제·MAD·시간 표, 식 (10)–(23), 교차 전파 및 정규화 순서, 코드 버전별 가중치·손실·평가 경로.
- arXiv 본문 링크의 fragment가 실제 HTML id에 존재하는지 확인했다.
- 숫자의 재계산과 독립 대수 예제는 [validation.json](./validation.json)에 기록했다.
